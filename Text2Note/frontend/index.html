ABOUT TEXT2NOTE

A notebook tool built by students, for students.

Text2Note started as a hackathon idea: what if typed text could be placed onto notebook pages without rewriting everything by hand?

The goal is simple—upload, customize, preview and export a note that feels like it belongs on the page.
